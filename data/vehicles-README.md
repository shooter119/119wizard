## 💡 使用示例

### Python 查询示例

```python
import json

# 读取数据
with open('data/vehicles.json', 'r', encoding='utf-8') as f:
    vehicles = json.load(f)

# 查询特定消防站的车辆
def get_vehicles_by_station(station_name):
    return [v for v in vehicles if v.get('消防站名称') == station_name]

# 查询特定类型的车辆
def get_vehicles_by_type(vehicle_type):
    return [v for v in vehicles if v.get('车辆名称') == vehicle_type]

# 查询载水量大于X吨的车辆
def get_vehicles_by_water_capacity(min_tons):
    return [v for v in vehicles if v.get('载水量吨', 0) >= min_tons]

# 计算消防站总载水量
def calculate_station_water_capacity(station_name):
    station_vehicles = get_vehicles_by_station(station_name)
    return sum(v.get('载水量吨', 0) for v in station_vehicles)

# 示例：查询永安路消防救援站
yongan_vehicles = get_vehicles_by_station('永安路消防救援站')
print(f"永安路站共有{len(yongan_vehicles)}辆车")
for v in yongan_vehicles:
    print(f"  - {v.get('车辆名称')}: {v.get('车牌号')}")
    if v.get('载水量吨'):
        print(f"    载水量: {v.get('载水量吨')}吨")
```

### JavaScript 查询示例

```javascript
// 读取数据（在浏览器中）
fetch('data/vehicles.json')
  .then(response => response.json())
  .then(vehicles => {
    // 查询永安路消防救援站的车辆
    const yonganVehicles = vehicles.filter(v =>
      v['消防站名称'] === '永安路消防救援站'
    );

    console.log(`永安路站共有${yonganVehicles.length}辆车`);

    // 计算总载水量
    const totalWater = yonganVehicles.reduce((sum, v) =>
      sum + (v['载水量吨'] || 0), 0
    );

    console.log(`总载水量: ${totalWater}吨`);
  });
```

## 🔄 数据更新

### 更新流程

1. **获取最新数据**：从消防支队获取最新的车辆统计表
2. **转换数据格式**：运行转换脚本将Excel转换为JSON
3. **验证数据**：检查数据完整性和准确性
4. **替换旧数据**：用新数据替换 `vehicles.json` 文件
5. **更新文档**：更新本说明文档和统计数据

### 数据清洗规则

- 去除空白行和无效数据
- 清理空值字段（删除 `null`、`''`、`'nan'`）
- 数值字段统一为数字类型
- 日期字段格式统一

## ⚠️ 注意事项

1. **数据时效性**：车辆信息会随时间变化，建议定期更新
2. **敏感信息**：包含车辆识别代码、发动机号等敏感信息，注意保密
3. **数据准确性**：部分字段可能为空或不完整
4. **单位说明**：
   - 载水量、泡沫量、干粉量：吨
   - 底盘功率：千瓦（kW）
   - 举升高度、跨距：米（m）
   - 消防泵压力：兆帕（MPa）
   - 消防炮流量：升/秒（L/s）
   - 排烟量：立方米/小时（m³/h）
